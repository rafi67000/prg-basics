# **Operatory Arytmetyczne** (wynik w postaci liczby)

`+` Addition (dodawanie)

`*` Multiplication (mnożenie)

`**` Exponentiation (potęgowanie)

`/` Division (dzielenie)

`//` Floor division (pierwiastkowanie)

`%` Modulo (reszta z dzielenia)

# **Comparatory** (wynik w postaci boolean)

### `>` Greater than (Mniejsze niż)
1 > 0 == true
### `<=` Less than or equal to (Mniejsze niż lub równe)
2 <= 3 == true
2 <= 2 == true
